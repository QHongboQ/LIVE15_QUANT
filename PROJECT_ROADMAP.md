# LIVE15 approved roadmap index

This is the durable index for user-approved forward planning that is too detailed for the compact Project Brain bootstrap. It complements `PROJECT_PROGRESS.md`; it does not replace current task status, architecture authority, runtime truth, or evidence artifacts.

## Read rule

For any task involving model training, adaptive learning, factors, H2/DepthFeed, model selection, Router/decision policy, or live-action policy, read **all roadmap volumes listed here in full** before planning or implementation.

Do not compress or silently omit requirements to satisfy the Project Brain token budget. The compact bootstrap files stay small; detailed planning is split into numbered volumes.

### Volume sizing rule

- Target maximum per detailed roadmap volume: about **4,500 estimated tokens**.
- If a volume would exceed that size, create the next numbered volume instead of deleting detail.
- New requirements must preserve provenance: approved direction vs implemented fact vs evidence-backed completion.
- Roadmap text is planning authority only where it does not conflict with `PROJECT_CHARTER.md`, accepted ADRs, Research Data Authority, Hard Risk, or current live evidence.
