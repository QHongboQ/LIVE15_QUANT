# Architecture decision records

## Status vocabulary

- **Accepted (existing)**: a durable decision already implemented and evidenced
  elsewhere; this ADR records its source and consequences.
- **Proposed**: a decision request, not an authority to implement.
- **Superseded**: retained for lineage with a link to the replacement.
